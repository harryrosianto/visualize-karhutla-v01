# visualize-karhutla-v01

Repositori penampung unggahan karya warga untuk [Visualize Karhutla](https://github.com/harryrosianto/visualize-karhutla).

Berkas pada folder `uploads/` dibuat otomatis oleh Worker situs ketika seseorang mengirim karya lewat formulir (tanpa akun GitHub). Berkas di sini **belum disetujui**: karya hanya tayang di situs setelah pemelihara meninjau isu terkait di repositori utama dan memasang label `setujui-templat`.

Jangan menyunting folder `uploads/` secara manual. Gambar bermasalah dapat dihapus dari sini tanpa menyentuh repositori utama.
